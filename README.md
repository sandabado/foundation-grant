# Whole Body Foundation — Interactive Field Presentation

An immersive, responsive presentation for Whole Body Foundation’s Mojave Desert ecological research initiative.

## Experience

- Interactive metal-free geodesic dome model
- Clickable tetrahedron garden plan
- Magnetic field survey visualization
- Transparent year-one budget
- 18-month roadmap
- Team, advisor openings, and grant contact

## Local development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run build
```

No environment variables are required for the presentation.
